KKTC TÜFE RESTful API Kılavuzu

Resmi KKTC Başbakanlık İstatistik Kurumu bülten ve arşivlerini (1977'den günümüze) otomatik takip eden, geliştiricilerin doğrudan web, mobil, finans veya muhasebe uygulamalarına bağlayabileceği açık kaynaklı RESTful API.

Canlı API URL https://kktc-tufe-api.stevevaius.workers.dev
Veri Derinliği 1977 – Ağustos 2026 (594 Kayıt)
Altyapı & Yanıt Süresi Cloudflare Edge (~15 ms)
Lisans & Maliyet MIT • Tamamen Ücretsiz
🚀

Hızlı Başlangıç (Quickstart)

API anahtarı veya kayıt gerektirmeden hemen terminalinizden veya kodunuzdan doğrudan çağrı yapabilirsiniz: 

curl -s "https://kktc-tufe-api.stevevaius.workers.dev/api/v1/latest"
💡 İpucu: Tüm yanıtlar standart application/json formatında döner ve CORS tüm alan adlarına açıktır. Frontend (React, Vue, Flutter, iOS, Android) uygulamalarınızdan doğrudan çağırabilirsiniz.

En Son Açıklanan Enflasyon Oranı

Resmi olarak duyurulan en güncel ayın TÜFE oranlarını (aylık değişim, yılbaşından bu yana ve yıllık enflasyon) ve içinde bulunulan yılın dönem durumunu döndürür.

⚡ Canlı Yanıtı Gör
GET /api/v1/tufe
Zaman Serisi Filtreleme ve Sayfalama

1977'den günümüze tüm enflasyon verilerini gelişmiş parametrelerle filtreler.

Parametre Tip Durum Açıklama & Örnek
start_year integer Opsiyonel Başlangıç yılı (örn: 2023)
end_year integer Opsiyonel Bitiş yılı (örn: 2024)
month integer Opsiyonel Sadece belirli bir ay (örn: 6 = Haziran)
sort string Opsiyonel Sıralama yönü: asc (kronolojik) veya desc (en yeni başta)
limit integer Opsiyonel Maksimum kayıt adedi (örn: 10)
⚡ Canlı Test: /api/v1/tufe?start_year=2024&limit=3&sort=desc
GET /api/v1/tufe/:year
Belirli Bir Yılın 12 Aylık Dökümü & İstatistikleri

Belirtilen yıla ait tüm ayların dökümünü, ortalama aylık enflasyonu, en yüksek ve en düşük ayları ile dönem özetlerini döndürür.

⚡ Canlı Test: /api/v1/tufe/2024

Sepet Madde Fiyatları (2015 – 2026 / 520 Kalem)

KKTC Tüketici Fiyat Endeksi sepetinde yer alan 520 mal ve hizmet kaleminin (ekmek, pirinç, et, süt, akaryakıt, kira, elektrik, muayene ücreti vb.) Ocak 2015'ten günümüze kadar olan tüm resmi aylık fiyatları, değişim oranları ve karşılaştırma motoru.

GET /api/v1/items
520 Kalemin Tam Listesi & Arama

Sepetteki tüm ürünleri listeler. Arama (?search=ekmek) ve sayfalama destekler. İlk fiyat (2015), son fiyat ve kümülatif artış oranını özetler.

Parametre Tip Durum Açıklama
search string Opsiyonel Ürün adında veya slug'ında arama (örn: ekmek, benzin, et)
limit integer Opsiyonel Döndürülecek ürün sayısı (varsayılan: 50)
offset integer Opsiyonel Atlanacak kayıt sayısı (sayfalama için)
⚡ Canlı Test: /api/v1/items?search=ekmek
GET /api/v1/items/:item
Tekil Kalem Aylık Fiyat Geçmişi & Artış İstatistikleri

Belirtilen ürünün (örn: ekmek, benzin, dana-eti-taze) 2015'ten Temmuz 2026 dönemine kadar 139 aylık kesintisiz fiyat geçmişini, her ayın bir önceki aya göre yüzde değişimini ve min/max istatistiklerini getirir.

Parametre Tip Durum Açıklama
item string Zorunlu URL yolu: Ürün slug'ı veya adı (örn: ekmek, benzin, Ekmek)
start_year / end_year integer Opsiyonel Yıl bazında filtreleme (örn: start_year=2020&end_year=2024)
sort string Opsiyonel Sıralama: asc (kronolojik) veya desc (en yeniden eskiye)
⚡ Canlı Test: /api/v1/items/ekmek
GET /api/v1/prices
Belirli Bir Ayın Tüm Sepet Fiyat Dökümü

Seçilen aydaki (ör: Ocak 2024) tüm sepet kalemlerinin o aydaki fiyatlarını ve bir önceki aya göre değişim yüzdesini döndürür.

Parametre Tip Durum Açıklama
period string Opsiyonel Dönem formatı: YYYY-MM (örn: 2024-01)
search string Opsiyonel İlgili ay içinde ürün adı arama (örn: et, peynir)
limit integer Opsiyonel Döndürülecek kayıt sayısı (varsayılan: 50)
⚡ Canlı Test: /api/v1/prices?period=2024-01&limit=5
GET /api/v1/items/compare
Çoklu Kalem Enflasyon & Fiyat Karşılaştırması

Birden fazla ürünün fiyat seyrini ve artış oranlarını tek çağrıda yan yana karşılaştırır.

Parametre Tip Durum Açıklama
items string Zorunlu Virgülle ayrılmış ürün slug'ları (örn: ekmek,pirinc,benzin)
start_period / end_period string Opsiyonel Zaman aralığı filtreleme (örn: start_period=2020-01&end_period=2024-01)
⚡ Canlı Test: /api/v1/items/compare?items=ekmek,pirinc,benzin

KKTC Hayat Pahalılığı & Maaş Endeksleme Dönemleri

KKTC yasaları gereği kamu maaşları, emekli maaşları ve asgari ücret yılda iki kez 6 aylık hayat pahalılığı kümülatiflerine göre artırılır.

GET /api/v1/periods?year=2024
6 Aylık Kümülatif Oranlar
  • 1. Dönem (Ocak – Haziran): Haziran ayının resmi "Yılbaşından Bu Yana" kümülatif değişim oranıdır.
  • 2. Dönem (Temmuz – Aralık): Temmuz'dan Aralık'a kadar olan aylık değişimlerin bileşik çarpımıdır: ∏ (1 + r_i/100) - 1.
⚡ Canlı Test: /api/v1/periods?year=2024
🧮

Enflasyon & Alım Gücü Değerleme Aracı

Geçmişteki belirli bir tarihteki paranın (örneğin Ocak 2023'teki 10.000 TL), hedeflenen tarihteki veya günümüzdeki reel alım gücü karşılığını otomatik hesaplar.

GET /api/v1/calculate
Bileşik Değerleme Formülü
Parametre Tip Durum Açıklama
start_year integer Zorunlu Başlangıç yılı (örn: 2023)
start_month integer Zorunlu Başlangıç ayı (1-12, örn: 1)
end_year integer Opsiyonel Bitiş yılı (boşsa en güncel ayın yılı)
end_month integer Opsiyonel Bitiş ayı (boşsa en güncel ay)
amount number Opsiyonel Değerlenecek ana para (varsayılan: 100)
⚡ Canlı Test: /api/v1/calculate?start_year=2023&start_month=1&amount=10000

Kod Örnekleri (JavaScript & Python)

Kendi uygulamanızda verileri kullanmak için hazır kod şablonları:

JavaScript (Fetch API)

// Son enflasyon verisini çek
const response = await fetch("https://kktc-tufe-api.stevevaius.workers.dev/api/v1/latest");
const { data } = await response.json();

console.log(`Dönem: ${data.monthName} ${data.year}`);
console.log(`Aylık Enflasyon: %${data.aylikYuzde}`);
console.log(`Yıllık Enflasyon: %${data.yillikYuzde}`);

// Sepet ürünü fiyat geçmişi (Örn: Ekmek)
const resEkmek = await fetch("https://kktc-tufe-api.stevevaius.workers.dev/api/v1/items/ekmek");
const ekmekData = await resEkmek.json();
console.log(`Ekmek 2015 Fiyatı: ${ekmekData.data.statistics.firstPrice} TL`);
console.log(`Ekmek Güncel Fiyat: ${ekmekData.data.statistics.latestPrice} TL`);
console.log(`Toplam Artış Oranı: %${ekmekData.data.statistics.totalChangePercentage}`);

Python (urllib - Harici kütüphane gerektirmez)

import urllib.request
import json

# Genel TÜFE verisi
url = "https://kktc-tufe-api.stevevaius.workers.dev/api/v1/latest"
with urllib.request.urlopen(url) as res:
    payload = json.loads(res.read().decode())
    data = payload["data"]
    print(f"Dönem: {data['monthName']} {data['year']}")
    print(f"Aylık: %{data['aylikYuzde']} | Yıllık: %{data['yillikYuzde']}")

# Sepet ürünü sorgulama (Benzin)
url_benzin = "https://kktc-tufe-api.stevevaius.workers.dev/api/v1/items/benzin"
with urllib.request.urlopen(url_benzin) as res:
    benzin = json.loads(res.read().decode())["data"]
    print(f"Benzin Güncel Fiyat: {benzin['statistics']['latestPrice']} TL (Artış: %{benzin['statistics']['totalChangePercentage']})")
